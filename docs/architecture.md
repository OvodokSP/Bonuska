# Бонуска — Architecture v0.1

## Размещение

- GitHub — исходный код, документация, история изменений.
- VPS — работающий сервис в Docker.

## Иерархия данных

Расчёт месяца → Проект → Счёт → Бренды и суммы.

## Обработка файлов

Исходные файлы принимаются временно, обрабатываются и удаляются. В системе остаются только структурированные данные.

## Первый технический модуль

PDF parser:
- извлечь номер счёта;
- извлечь дату;
- извлечь табличные позиции;
- для каждой позиции получить наименование и сумму строки;
- определить бренд;
- сгруппировать суммы по брендам.
