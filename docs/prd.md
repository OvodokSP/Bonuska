# Бонуска — PRD v0.1

## MVP

1. Создание расчёта за месяц.
2. Заполнение шапки: ФИО, месяц, год, оклад, максимальная премия, планы месяца/года.
3. Добавление счёта с указанием номера проекта.
4. Если проект новый — ввод данных проекта: клиент, объект, менеджер, стадия, поддержка.
5. Если проект уже есть — данные проекта подтягиваются автоматически.
6. Распознавание счёта PDF/XLSX: номер счёта, дата, табличная часть, наименование, сумма строки.
7. Определение бренда по правилам.
8. Группировка: расчёт → проект → счёт → бренд → сумма.
9. В свернутом проекте показывать суммы по брендам из всех счетов проекта.
10. Excel выгружается только в конце расчёта.

## Не входит в MVP

- OCR для сканов.
- Полная методика бонусного процента.
- Интеграция с 1С.
- Хранение исходных файлов счетов.
