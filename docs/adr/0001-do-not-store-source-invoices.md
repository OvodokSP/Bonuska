# ADR-0001: Не хранить исходные счета

## Статус
Принято.

## Решение
Исходные PDF/XLSX счета не хранятся на сервере как постоянные файлы.

## Причина
Сервису нужны только структурированные данные: номер счёта, дата, проект, клиент, объект, бренд и сумма.

## Последствия
- Снижается нагрузка на диск.
- Снижаются риски хранения коммерческих документов.
- Для повторной проверки пользователь должен загрузить исходный файл заново.
