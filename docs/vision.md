# Бонуска — Vision

Веб-сервис для автоматизации бонусной ведомости инженера.

Пользователь создаёт расчёт месяца, заполняет шапку, добавляет счета PDF/XLSX по проектам, проверяет распознанные бренды и суммы, затем получает итоговый расчёт/Excel.

Ключевая ценность: убрать ручное разнесение товарных позиций по брендам.
