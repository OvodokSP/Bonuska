# Бонуска

Веб-сервис для автоматизации бонусной ведомости инженера по счетам PDF/XLSX.

## Первый запуск парсера

```bash
cd backend
pip install -r requirements.txt
python parse_pdf_demo.py "путь/к/счету.pdf"
```

На первом этапе парсер возвращает JSON: номер счёта, дату, товарные позиции, бренд и сумму.
